# Task 08 — Weekly sync flow

**Spec:** [docs/rules.md](../docs/rules.md#4-sync)

## Must
- Build a sync agenda: changing facts due for review + open review-queue items + 3–5 new questions from the week's entries.
- Each item answered with yes / no / "changed to…" (voice transcript or text).
- Write answers through the store (history kept) and close queue items.
- Output a short sync log.

## Done when
Tests cover agenda building and each answer type.
