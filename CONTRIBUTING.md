# Contributing to كن إنسان

Thank you for wanting to build this with us. Everything is open: design, specs, prompts, templates and code.

## Fastest way in
1. Pick a task from [tasks/](tasks/).
2. Open an issue **"Taking: task NN"** so nobody duplicates it.
3. Build it (AI-assisted is welcome; you own the result and its quality).
4. Send a pull request with tests.

## Roles
| Role | How you get there | What you do |
|---|---|---|
| **Contributor** | Anyone who sends a PR | Build tasks, review, improve docs |
| **Core builder** | Proven, merged contributions + lives the principles | Write access, design decisions, reviews |
| **Tester** | Apply (below) | Use it on a real problem, give honest feedback |

Moving up is based on the quality of your contributions and how well you live the principles, not on time or titles.

## Apply to be a core builder or tester
Open an issue titled **`Apply: <your name>`** and tell us:
1. Who you are and what you've built (links)
2. How you understand AI and where you add value
3. Why you want to build كن إنسان, and which principle matters most to you
4. A real problem in your life or work this should solve

Shortlisted people get a short call with a real human from the team.

## Ground rules
- **Sign your commits** (Developer Certificate of Origin): `git commit -s`.
- **Never commit personal data**, credentials, API keys or real user content. Synthetic examples only.
- Guardrails ([docs/guardrails.md](docs/guardrails.md)) are enforced in code, not only in prompts.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Discuss big changes in an issue before writing code.

## Recognition
Contributors are credited by name. Nobody succeeds alone.
