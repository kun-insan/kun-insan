# Start your own instance today

You don't need to wait for the app. Any capable AI assistant with memory or a project/notes space can run the method now.

1. Paste [../prompts/system-prompt.en.md](../prompts/system-prompt.en.md) (or the Arabic one) as the assistant's instructions.
2. Copy [instance-template.md](instance-template.md) into a private notes page you own. That's your memory.
3. Answer [onboarding-questions.md](onboarding-questions.md) by voice or text.
4. Set a weekly sync (30 min): facts review + a few new questions.
5. Follow the feeding rules in [../docs/rules.md](../docs/rules.md#10-feeding-rules-for-best-accuracy).

Keep your instance **private**. Never commit it to any repo.
