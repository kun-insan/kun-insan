# First use case: the meeting companion

For meetings where you're not the main topic but must be there, listen, and know if something goes wrong.

## v1 (permission level 1: Suggest)
- Joins with the full background from one source of truth (the user's memory blocks).
- **Attends, doesn't talk.**
- Right after: emails a summary + **the action points that are yours**.
- Alerts you if something off or unbalanced happened.

## Later (earned, possibly paid)
Acts after the meeting with specific permissions (draft follow-ups → send with approval → act alone within limits), unlocked by accuracy.

## Rules
- **Consent:** everyone in the meeting must agree to recording/transcription. Start with internal team meetings.
- Facts from meetings enter memory as **inferred**, with the meeting as source, until the user confirms.
- No client confidential details leave the user's private space.
