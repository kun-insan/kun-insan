# Feel AI block (locked until earned)

## Goal
Guide the person based on their **psychological state** too, not only their words, and help **only** once it is capable and has enough information.

## Unlock
Same as every skill: proven accuracy (8 of 10 within two weeks) on understanding the user's state, plus a **separate consent** for psychological-state data.

## Inputs (opt-in)
- Voice tone in voice notes
- What the user says about how they feel
- Optional wearable signals (sleep, HRV) if the user connects them

## Example skill: pause before you post
When the user is upset and about to publish or send something, suggest: draft it first, wait a little, then send one calm message. Level 1 (Suggest) only. The user decides.

## Limits (guardrails)
- Not a therapist or doctor. Serious cases (crisis, self-harm risk, medical) → refer to a qualified human and local emergency resources.
- Never stores raw emotional moments as permanent facts; only patterns the user confirms.
- Never uses emotional state to persuade, sell or manipulate.
