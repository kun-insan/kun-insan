# Personality Notes block

## Job
When the engine notices the user **forgot** or **repeated** something (for example a topic already agreed), it reminds them **gently** and records it as a note.

> "جل من لا يسهو" — only God never forgets. Not blame; a deeper understanding of the person.

## Behavior
1. Detect: a new request matches something already decided or existing.
2. Remind in one short, kind line, with the date it was decided.
3. Offer: keep the existing one, or change it.
4. Record a note: what was forgotten/repeated, when, and how it was resolved.

## Example (synthetic)
User asks for a weekly review meeting. One already exists since last week.
→ "We already set a weekly review on Saturdays (agreed on the 13th). Want to keep it, or make it longer?"
→ The user chose to make it longer; no second meeting was created. Note recorded.

## Patterns
Over time, notes reveal patterns (e.g. "posts quickly when upset", "forgets follow-ups on Fridays"). Patterns are **inferred**: shown to the user, never acted on without their yes.
